# React Learning Projects 🚀

This repository contains my React practice projects and exercises while learning React.js. The goal of this repository is to strengthen my understanding of React fundamentals, component-based architecture, state management, props, hooks, event handling, and modern frontend development concepts.

## 📚 Topics Covered

* JSX
* Components
* Props
* State Management (`useState`)
* Event Handling
* Conditional Rendering
* Lists & Keys
* React Hooks
* Forms and User Input
* Shopping Cart Features
* Dynamic UI Updates
* CSS Styling in React

## 🛠️ Technologies Used

* React.js
* JavaScript (ES6+)
* HTML5
* CSS3
* Vite

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/prathamcodes04/react-11.git
```

### Navigate to the Project Folder

```bash
cd react-11
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```

The application will run locally on:

```bash
http://localhost:5173
```
